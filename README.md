# 计算稿纸 · Notepad Calculator

计算稿纸风格的 Web 应用。

## 快速开始

```bash
npm install
npm run dev
```

## 功能

| 功能 | 示例 |
|---|---|
| 变量赋值 | `月薪 = 3000` |
| 引用变量 | `年收入 = 月薪 * 12` |
| 基础/高级数学 | `sin(pi/2)`、`sqrt(16)`、`2^10` |
| 单位换算 | `100 kg to lb`、`36.6 degC to degF` |
| 中文单位 | `100公斤 to 磅`、`1英里 to km` |
| 日期计算 | `today + 90天`、`今天距2027-01-01` |
| 汇率换算 | `1000 USD to CNY`（实时，每小时更新） |
| 注释 | `# 这是注释` 或 `// 注释` |
| 自动求和 | 多行数值时底部显示 ∑ |


## 依赖

- **mathjs** — 核心计算引擎，支持单位、变量、矩阵
- **chrono-node** — 自然语言日期解析
- **frankfurter.app** — 免费汇率 API
